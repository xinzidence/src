Hello from Azure App Service

A simple static webpage deployed to Azure

About This Page

This page was deployed to Azure App Service as a demonstration of static web hosting. It uses only plain HTML and CSS, so it will run on any web server without additional configuration.

What This Demonstrates

  • Hosting a static page with Azure App Service
  • Serving HTML and CSS from the wwwroot folder
  • Accessing the page through a public Azure URL
